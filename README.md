# Time Tracker

A lightweight weekly time-tracking web app for tracking work hours, leave, daily targets, and weekly hour balances.

### Features

* Track daily clock-in and clock-out times
* Automatically calculate daily worked hours
* 9-hour daily and 45-hour weekly work targets
* Support for leave days with automatic target adjustment
* Calculate daily surplus/deficit hours
* Track weekly and carry-forward balances
* Suggest today's clock-out time based on previous balance
* Live timer showing time elapsed since clock-in
* Automatically save data using browser `localStorage`
* Reset individual days or clear the entire week
* Responsive layout for desktop and mobile

### Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Browser LocalStorage

A simple, dependency-free time tracker designed for quickly managing weekly work-hour calculations directly from the browser.
